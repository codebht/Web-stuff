# UDAAN EK GAON KI

Simple, responsive school project website made with HTML, CSS and vanilla JavaScript. No images, frameworks or build step required.

## Files
- `index.html` — website content
- `styles.css` — design, responsive layout and smooth hover transitions
- `script.js` — mobile navigation and current year
- `vercel.json` — Vercel deployment configuration
- `assets/favicon.svg` — simple text favicon

## Before publishing
In `index.html`, replace these two placeholder URLs in the Code & Diagrams section:
- `https://github.com/your-username/your-repository`
- `YOUR_DIAGRAMS_LINK`

## Deploy
Import this folder's GitHub repository into Vercel. Select **Other** as the framework preset. Leave Build Command and Output Directory empty, then deploy. You can also run `vercel` from this directory using the Vercel CLI.
